About SiliconBadgers

We’re a student chip-design club at UW–Madison. Learn digital logic, write and test hardware code, and work toward a chip design with other students. You can join without prior experience.

Our first project is an AI-inference accelerator that can run Qwen3.5. We plan on taping it out next year.

From AI to Silicon

AI Model

Defines the neural network and its computations.

Compiler

Translates the model into hardware-targeted instructions.

ISA

Defines the instructions the processor can execute.

RTL

Describes the digital logic that implements the processor.

CHIP

The physical silicon that executes the computations.

Skills You Can Build

Start with a small working design, then follow it from code to hardware.

Digital Design

SystemVerilog · logic

Write your first SystemVerilog module. Connect logic gates, build a small datapath, and see what changes on each clock cycle.

Both inputs high → output high.

Verification

Testbenches · waveforms

Write a testbench, inspect a waveform, and track a failing test back to the line of hardware code that caused it.

Follow a signal through three clock cycles.

Physical Design

Placement · routing

Place chip blocks, route the connections between them, and check whether signals arrive before the next clock edge.

Four blocks settle into a connected layout.

Software & Machine Learning

Python · compilers

Take a model operation, translate it into processor instructions, and compare the result in a simulator.

A tiny network becomes instructions; the processor produces an output.
